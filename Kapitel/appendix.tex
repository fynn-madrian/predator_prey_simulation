\begin{itemize}

  \item Branch single\_agent enthält den Code für das Taskspezifische Single-Agenten Training

\end{itemize}

\section{Animationsclips}
\label{app:animations}

Um die Verhaltensweisen der trainierten Modelle zu illustrieren, wurden ausgewählte Durchläufe als Animationsclips exportiert. Die Videodateien sind im Repository unter dem Verzeichnis \href{https://github.com/fynn-madrian/predator_prey_simulation/tree/single_agent/animated_runs}{\texttt{/animated\_runs}} abrufbar:

\begin{itemize}
\item \href{https://github.com/fynn-madrian/predator_prey_simulation/blob/single_agent/animated_runs/circle_field.gif}{\texttt{circle\_field}} zeigt einen Agenten, der ein Feldstück leert, und währenddessen dem Jäger ausweicht
\item \href{https://github.com/fynn-madrian/predator_prey_simulation/blob/single_agent/animated_runs/flee_river.gif}{\texttt{flee\_river}} zeigt einen Agenten, der durch einen engen Kartenabschnitt läuft, um dem Jäger zu entkommen
\item \href{https://github.com/fynn-madrian/predator_prey_simulation/blob/single_agent/animated_runs/flee_rocks.gif}{\texttt{flee\_rocks}} zeigt eine Fluchtumgebung mit großen Steinen
\item \href{https://github.com/fynn-madrian/predator_prey_simulation/blob/single_agent/animated_runs/spinning_navigate.gif}{\texttt{spinning\_navigate}} zeigte einen Agenten in einer Navigationsumgebung
\end{itemize}
